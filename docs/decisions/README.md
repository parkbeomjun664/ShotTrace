# 설계 결정 기록 (ADR)

> **"왜 그렇게 했습니까"가 면접의 90%다.**
> 6개월 전 결정을 기억으로 복원하는 건 불가능하다. 그때그때 3줄씩 남긴다.

## 언제 쓰나

되돌리기 어렵거나, 나중에 "왜 이렇게 했지?"라고 물을 만한 결정을 내렸을 때.

- 타입을 골랐을 때 (`timestamptz` vs `timestamp`)
- 구조를 정했을 때 (FK를 안 걸기로 함)
- 무언가를 안 하기로 했을 때 (죽은 컬럼 12개를 뺌)
- 도구를 골랐을 때 (Jest 대신 Vitest)

**안 써도 되는 것** — 코드를 읽으면 바로 알 수 있는 것, 되돌리기 쉬운 것.

## 형식

파일명은 `NNN-짧은-제목.md`. 번호는 순서대로 증가하며 재사용하지 않는다.

```markdown
# NNN. 제목

- **상태**: 채택 | 폐기 | NNN으로 대체됨
- **날짜**: 2026-08-17
- **관련 모듈**: M07

## 무엇을 정했나
한 문단.

## 왜
근거. 측정한 수치가 있으면 여기에.

## 버린 대안
무엇을 고려했고 왜 안 골랐는지. **이 항목이 가장 중요하다** —
꼬리질문은 대부분 "다른 방법은 없었나요?"로 들어온다.
```

세 항목이면 충분하다. 길게 쓰려다 안 쓰게 되는 게 최악이다.

## 아직 안 쓴 것 — 결정하면 바로 기록

> ~~가상 시계~~ → [010](010-시간의-설계.md) · ~~수집기 상시 구동 위치~~ → [011](011-수집기-구동-위치.md)

**S05~S06 에서 결정해야 하는 것**

- [x] **`production_lot` 집계값** — **매번 계산한다** (2026-10-05 · `010_live_summary.sql`)
      현황판 View 를 `shot_part` 원본 집계로 바꿨다. 저장값은 샷이 들어와도 안 변해서
      실시간이 성립하지 않았다. 샷이 원본, 집계는 파생 — ADR 008 의 방향 그대로다
- [x] **미할당 생산** — **생산량에는 잡힌다** (2026-10-05)
      `shot_part` 기준 집계라 LOT 밖 샷도 자동으로 세어진다. 교체 시점 기준 **0건**.
      🔴 남은 꼬리 — `lot_count` 와 `total_qty` 의 **기준이 달라진다**. LOT 밖 샷이
      생기면 "LOT 25건 / 생산 5,233개" 가 되고, 화면이 그걸 드러내야 한다
- [x] **화면 갱신 정책** — **Realtime 구독 + 1초 throttle + `revalidate = 0`** (2026-10-05)
      `shot_part` 변경 알림을 **신호로만** 쓰고 값은 `router.refresh()` 로 서버에서 다시 받는다.
      폴링은 버렸다. 📝 **ADR 012 로 금요일에 쓴다** — ①~③이 한 덩어리다

- [x] **MVP 데모 데이터** — **데모 모드 + 새 LOT** (2026-10-06 · 구현은 10/7)
      `replay.py --live` 로 지금 시각부터 **1배속**으로 흘리고, 받을 **데모 LOT 을 하나
      열어둔다**(`ended_at = 'infinity'`). 🔵 ADR 010 이 버린 세 안(벽시계 덮기 · 오늘
      날짜로 · 배속 압축)을 전부 피한다 — 2020 LOT 을 안 건드리고, 미래가 안 되고,
      `cycle_time` 과 간격이 어긋나지 않는다. 덤으로 진행 중 LOT 과 EXCLUDE 가
      시연에서 처음 눈에 보인다. 🔴 비용은 1분에 한 샷
      📝 ADR 012 에 실시간 갱신 정책과 같이 쓸지는 금요일에 판단

- [x] **데모 데이터를 어떻게 치우나** — **기준은 "2026년 이후"** (2026-10-07)
      원본은 2020-10 ~ 11 뿐이라 섞이지 않는다. `scripts/demo/demo_lot.sql` 에 열기·닫기·
      치우기를 묶어뒀다. 🔴 치우는 순서는 `shot_part` → `shot` (FK) · 끝난 LOT 은 **닫는다**

- [ ] **LOT 목록이 저장값을 본다** — `/lots` 의 수량은 `production_lot` 그대로다 (M18 · M27)
      진행 중 LOT 이 `0개` 로 보인다. 🔴 25건 전부에 시간 구간 조인을 돌려야 해서
      **성능과 정확성의 교환**이다. 현황판·LOT 상세는 이미 샷 기준으로 옮겼다
