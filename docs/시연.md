## 막히면 (대안)

| 막힘 | 대안 |
|---|---|
| Docker · 수집기가 안 뜬다 | 실시간은 건너뛴다 — 현황판의 숫자만 보여주고 "지금은 재생을 안 켰다" 고 말한다. 나머지 흐름은 DB 만 있으면 된다 |
| 1분 안에 숫자가 안 바뀐다 | 기다리지 않고 LOT 추적으로 넘어간다. 끝에 다시 현황판으로 돌아와 바뀐 숫자를 보여준다 |
| 배포본이 느리다 · 안 열린다 | localhost(`npm run dev`)로 같은 순서. 그것도 안 되면 README 그림 + ADR 로 설명만 |
| 원장에 줄이 너무 많다 | 방금 저장한 줄은 맨 위다 (최근 순) |
