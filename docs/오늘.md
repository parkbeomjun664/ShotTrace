- 🔴 **`security_invoker = on` 을 빼면 View 가 RLS 를 우회한다.** S06 에서
  역할별 정책을 걸어도 View 로 보면 다 보인다 — 에러가 안 나서 모른다
- **`NULLIF(A, B)`** — 같으면 NULL. SQL 은 0으로 나누면 에러로 죽는다 (JS 는 NaN)

- **윈도우 함수 `OVER ()`** — `GROUP BY` 로 접은 **뒤** 결과 전체를 훑는다.
  `GROUP BY` 만으로는 "전체 대비 비율"을 못 만든다
- **View 컬럼은 타입이 전부 `| null`** — Postgres 가 NOT NULL 을 보장 못 한다
- 🔴 **`.reverse()` 와 `.sort()` 는 원본을 바꾼다.** `[...배열]` 로 복사하고 뒤집는다
- **DB는 값을 주고 화면은 모양을 정한다** — `25.00` 이 JSON 에서 `25` 가 되므로
  화면에서 `toFixed(2)`

**새로 보인 사실**

  최악은 2020-11-04 — 71개 중 7개, 수율 90.14%
- 5,232행일 때 안 보이던 것이 13행으로 접으니 보인다

**② Mosquitto — Started 는 떴다는 뜻이 아니다**
- 막힌 순서: Docker 미설치 → "Virtualization support not detected" → WSL 미설치
- CPU 가상화는 이미 켜져 있었다 (`VirtualizationFirmwareEnabled: True`).
  🔴 **메시지가 가리키는 곳이 원인이 아니었다** — 진짜 원인은 WSL
- `wsl --install` + 재시작 → Engine running
```
docker ps        Up 3 minutes · 0.0.0.0:1883->1883/tcp
docker logs      Config loaded ... / Opening ipv4 listen socket / version 2.1.2 running
```
- 🔴 세 가지가 전부 다르다
  - `Started` = **띄우라고 했다** (명령이 성공)
  - `Up` + 포트 = **떠 있다**
  - 로그의 `running` = **일하고 있다**
- 🔴 `starting` 과 `running` 사이에 에러가 없어야 진짜 뜬 것이다
- Docker Desktop 은 **엔진을 켜두는 앱**일 뿐, 명령은 터미널에서 친다.
  설정이 `docker-compose.yml` 에 있어야 git 에 남는다 (001_init.sql 과 같은 원칙)
