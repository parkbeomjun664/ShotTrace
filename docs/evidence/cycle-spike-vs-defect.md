# 사이클 타임 스파이크와 불량 — 관계 없음 (검증 실패 기록)

- **날짜**: 2026-09-14
- **계기**: 시계열 차트(M12)를 붙이자마자 사이클 타임 스파이크가 눈에 띄었다
- **결론**: **근거 없음.** 화면에 띄우지 않는다

---

## 관찰

`S14-20201104-RG3LH`(35샷) 차트에서 사이클 타임이 14:16~14:17 에 튀었고
(61.78 → 62.20), **2분 뒤 14:19:50 부터 불량 3건이 연속**으로 났다.

"사이클이 튀면 불량이 나나?" 를 확인해봤다.

## 1차 계산 — 그럴듯했다

전체 25개 LOT에서 "직전 3샷 안에 중앙값 +0.15초 이상 튐이 있었나" 로 나눴다.

| | 튐 있음 | 튐 없음 |
|---|---|---|
| 불량 | 11 | 49 |
| 양품 | 154 | 5,013 |

```
튐 뒤 불량률   6.67%   (11/165)
평소 불량률    0.97%   (49/5,062)
              6.9배
```

## 🔴 2차 계산 — 뒤집혔다

**불량은 연속으로 난다.** 위 계산은 연속 불량을 각각 독립으로 셌다.
연속 구간을 **한 사건**으로 묶으면 이렇게 된다.

```
불량 60건  →  실제로는 36번의 사건

직전에 튐 있었음     3건
없었음              33건
```

무작위 샷이 "직전에 튐"일 확률이 `165/5,232 ≈ 3.2%` 이고, 사건 기준은 `3/36 ≈ 8.3%` 다.
비율은 2.6배지만 **n = 3 이다. 아무것도 말할 수 없다.**

**자기상관을 무시하면 숫자가 부풀려진다.** 165개 "독립적인 기회"가 아니라
36번의 사건이었고, 그중 3번이다.

## 그래서

이 관계를 화면에 띄우지 않는다. "사이클이 튀면 불량률 6.9배" 는 그럴듯하고,
아무도 검증하지 않았을 것이고, **틀렸을 것이다.**

M24(LLM 대응 가이드)에서 불량 맥락을 넘길 때도 이 지표를 근거로 쓰지 않는다.

---

## 대신 셀 수 있는 사실

불량 36개 사건 중 **22건이 LOT 두 개에 몰려 있다.**

| LOT | 불량 사건 |
|---|---|
| `S14-20201022-RG3RH` | 15 |
| `S14-20201023-RG3RH` | 7 |
| 나머지 23개 LOT | 합쳐서 14 |

둘 다 `RG3 ... RH` 제품이고 연속된 이틀이다. **제품·기간 쪽을 보는 것이
사이클 타임을 보는 것보다 근거가 있다.**

## 패밀리 금형이 다시 확인됐다

```
S14-20201027-CN7LH  00:56:21  초기허용불량
S14-20201027-CN7RH  00:56:21  초기허용불량
```

**같은 샷에서 LH·RH 가 동시에 불량**이다. ADR 005 의 모델이 현실을 담고 있다는 증거다.

## 남긴 이유

검증에 실패한 기록도 남긴다. 안 남기면 **6개월 뒤에 같은 그래프를 보고 같은 착각**을 한다.
그리고 "왜 그 지표는 안 쓰나요" 에 답할 근거가 된다.
